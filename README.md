# Customer Shopping Behavior Analysis using SQL

## Project Overview
This project analyzes customer shopping behavior and purchasing trends using SQL queries on a retail dataset. The analysis focuses on customer spending, discounts, subscriptions, product performance, shipping preferences, and customer segmentation.

## Tools Used
- MySQL
- GitHub
- SQL Workbench

## SQL Concepts Used
- Aggregate Functions
- GROUP BY
- Subqueries
- CASE Statements
- CTEs
- Window Functions
- ROW_NUMBER()

## Business Questions Solved

1. Revenue generated by male vs female customers
2. Customers who used discounts but spent above average
3. Top 5 highest-rated products
4. Average purchase comparison by shipping type
5. Subscriber vs non-subscriber spending analysis
6. Products with highest discount purchase percentage
7. Customer segmentation based on purchase history
8. Top 3 purchased products within each category
9. Repeat buyer subscription analysis
10. Revenue contribution by age group

## Key Insights
- Loyal customers contribute significantly to revenue
- Certain products perform better with discount strategies
- Subscription customers tend to spend more on average
- Product preferences vary across categories
